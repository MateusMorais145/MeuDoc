O desafio

Cada nota fiscal exigia uma nova rodada de cotação manual com transportadoras.

O cliente tinha uma rotina operacional pesada: para cada nota fiscal, era necessário consultar transportadoras manualmente pelo WhatsApp, aguardar retorno de valores, comparar opções e decidir qual frete usar para fechar a carga.

Além do tempo gasto, esse processo abria espaço para divergências, esquecimentos, decisões sem padronização e dificuldade para considerar todos os custos envolvidos na contratação do frete.

O objetivo foi transformar essa rotina em uma ferramenta automatizada, capaz de buscar os dados das notas, calcular os fretes disponíveis e entregar uma recomendação clara para o responsável pelo fechamento das cargas.

A solução

Uma calculadora conectada ao sistema, parametrizada com as regras do cliente.

A ferramenta foi conectada ao sistema do cliente para coletar automaticamente os dados das notas fiscais, sem necessidade de digitação manual ou envio individual para cada transportadora.

A partir desses dados, o sistema calcula o frete com todas as transportadoras cadastradas que atendem a praça, considera custos adicionais quando aplicável e monta um relatório com a comparação completa.

Como regra definida pelo cliente, o sistema também destaca a recomendação do frete com menor valor, facilitando a decisão do responsável pelo fechamento das cargas.

Dados e regras consideradas
  1. Dados das notas fiscais coletados automaticamente.
  2. Praça atendida por cada transportadora.
  3. Tabela de frete parametrizada.
  4. Custos adicionais quando existentes.
  5. Comparativo entre transportadoras disponíveis.
  6. Recomendação da opção mais econômica.
  7. Relatório completo para fechamento da carga.
Funcionamento

A ferramenta sai da nota fiscal e chega no relatório de decisão.

O fluxo foi desenhado para reduzir o esforço operacional e transformar a cotação em um processo padronizado, auditável e mais rápido para quem fecha as cargas.

01

Busca automática das notas

A ferramenta coleta diretamente no sistema os dados das notas fiscais que precisam ter o frete calculado, evitando digitação e consulta manual.

02

Validação da praça

O sistema verifica quais transportadoras do cliente atendem a praça relacionada à nota fiscal.

03

Cálculo do frete

Cada transportadora elegível tem seu frete calculado com base nas regras e tabelas parametrizadas.

04

Custos adicionais

Quando existem custos extras previstos na operação, eles são considerados no valor final do frete.

05

Relatório com recomendação

O responsável recebe a informação completa das notas, todos os valores de frete e a recomendação da opção mais barata conforme parametrização do cliente.

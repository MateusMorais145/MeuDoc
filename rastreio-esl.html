O desafio

A transportadora recebia chamadas repetitivas no WhatsApp apenas para informar rastreio.

Uma transportadora entrou em contato com uma dor simples, mas muito comum: clientes chamavam constantemente no WhatsApp para pedir informações sobre o rastreio da mercadoria.

Esse tipo de atendimento parece pequeno quando analisado isoladamente, mas se torna um gargalo quando acontece várias vezes ao dia, ocupando tempo da equipe com consultas repetitivas que poderiam ser feitas diretamente pelo cliente.

O desafio era criar uma forma prática para o cliente final consultar sua carga, sem depender de uma pessoa da transportadora para buscar a informação manualmente.

A solução

Uma ferramenta online conectada diretamente ao sistema da transportadora.

Foi criada uma ferramenta de consulta conectada ao sistema ESL, permitindo que o cliente final acesse o rastreio da sua carga usando os dados necessários para identificação da entrega.

Como o projeto inicial foi feito de forma gratuita, a ferramenta foi mantida online e pronta para uso. Ela pode atender transportadoras que utilizam o sistema ESL, desde que possuam o token necessário para consulta.

Fluxo da consulta
  1. Transportadora fornece o token ao cliente.
  2. Cliente acessa a ferramenta online.
  3. Cliente informa o token e os dados da carga.
  4. Ferramenta consulta diretamente o sistema ESL.
  5. Rastreio é exibido sem acionar atendimento manual.
  6. Transportadora reduz chamadas repetitivas no WhatsApp.
Funcionamento

O cliente consulta. A transportadora economiza tempo. A informação vem do sistema.

A ferramenta foi pensada para resolver uma rotina objetiva: tirar da equipe da transportadora o trabalho de responder manualmente perguntas de rastreio que o próprio cliente pode consultar.

01

Consulta com token individual

Cada cliente utiliza seu próprio token fornecido pela transportadora. Isso cria uma camada de separação entre clientes e evita uma consulta aberta sem controle.

02

Integração com ESL

A ferramenta se conecta diretamente ao sistema usado pela transportadora para buscar as informações reais de rastreio.

03

Uso gratuito e online

A solução foi mantida disponível para uso, facilitando o acesso de transportadoras que já utilizam o sistema ESL.

04

Versão personalizada para transportadoras

Para transportadoras interessadas em adquirir a ferramenta, é possível eliminar a necessidade do cliente final digitar o token em cada consulta, mantendo segurança por cliente e oferecendo uma experiência mais simples.

Resultado

A transportadora ganhou uma forma simples de reduzir atendimento repetitivo e dar autonomia ao cliente.

A ferramenta resolve uma dor direta: evitar que o cliente precise chamar alguém no WhatsApp apenas para saber o status da sua mercadoria.

Como a consulta é conectada ao sistema ESL, a transportadora consegue disponibilizar rastreio de forma prática, mantendo uma lógica de acesso por token e abrindo espaço para uma versão personalizada mais profissional.
